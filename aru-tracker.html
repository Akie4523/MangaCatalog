1. ดึงข้อมูลจากระบบ ARU โดยตรง

เรียก API ด้วยเซสชันที่ล็อกอินอยู่ในเบราว์เซอร์นี้
หมายเหตุเกี่ยวกับ CORS Policy:
หากเปิดเว็บจาก Localhost หรือโดเมนอื่น เบราว์เซอร์อาจบล็อกการดึงข้อมูล ให้ใช้วิธีใน ส่วนที่ 2 (วาง JSON หรือเลือกไฟล์) แทน

2. วางข้อมูล JSON หรือเลือกไฟล์

คัดลอกข้อมูล Response JSON จากระบบกิจกรรม ARU มาวาง หรือเลือกไฟล์ .json ที่ดาวน์โหลดไว้
